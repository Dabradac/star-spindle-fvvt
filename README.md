# Звёздное Веретено — система для Foundry VTT

Игровая система для настольной ролевой игры «Звёздное Веретено» (Star Spindle) на Foundry VTT **v13+**.
Листы повторяют бумажные чарники (персонаж и корабль), механика — по основной книге правил.

## Установка

**Через манифест** (после первого релиза на GitHub):
Foundry → *Game Systems* → *Install System* → вставить ссылку на манифест:

```
https://github.com/dabradac/star-spindle_fvvt/releases/latest/download/system.json
```

**Вручную (для разработки):** склонировать репозиторий в `Data/systems/star-spindle`
(папка должна называться так же, как `id` в `system.json`).

## Что есть в системе

### Актёры

| Тип | Что на листе |
|---|---|
| **Персонаж** | имя, портрет, сверкредиты, репутация, скорость (м/ход), специализация, уровень и опыт; Здоровье (Телосложение + Ловкость) и Воля (Интеллект + Эмпатия); 4 характеристики и 16 навыков со столбцом «Хар.+Нав.»; специальные навыки; положительные и отрицательные черты; травмы, болезни и временные эффекты; нагрузка (Телосложение×2 + Сила); ремесленные ресурсы I–V; оружие, броня, снаряжение, маленькие предметы, импланты и протезы; «Моя каюта» с хранением снаряжения; отношения группы с фракциями и кланами; внешность, биография, заметки |
| **НИП** | компактный лист: характеристики, навыки, Здоровье/Воля, оружие, броня, таланты, описание |
| **Корабль** | класс, размер, корпус, бонусы корпуса, изъян, базовая стоимость, дата последнего ТО, долг (изначальный, остаток, ежемесячный платёж); атрибуты (Прочность, Энергия, Манёвренность, Заметность, Броня, Скорость, Топливо — текущее/макс.), B-батареи; критические попадания; оружие корабля; базовые и дополнительные модульные отсеки с состоянием (в норме / сбоит / неисправен / крит. неисправен); улучшения; груз и грузоподъёмность; экипаж; бортжурнал |

### Предметы

Оружие · Броня · Снаряжение · Имплант / протез / киберимплант · **Особая способность** (от навыка) · Черта ·
**Специализация** (класс) · Травма / болезнь / состояние · Оружие корабля · Модульный отсек · Улучшение корабля · Груз.

У персонажа может быть только одна специализация: если перетащить новую, она заменит старую.

### Навыки

| Характеристика | Общие навыки | Профессиональные |
|---|---|---|
| Телосложение | Ближний бой, Сила | — |
| Ловкость | Стрельба, Проворство, Скрытность | Пилотирование |
| Интеллект | Наблюдательность, Выживание | Кибершаманство, Механика, Наука, Знахарство |
| Эмпатия | Влияние | Лидерство, Культура, Ведовство |

Профессиональный навык со значением 0 проверить нельзя (это можно отключить в настройках мира).

## Механика (по книге правил)

### Проверки пулом к20

* **Количество к20** = навык + связанная характеристика + снаряжение + сложность (от −3 до +3) + прочие факторы
  (помощь союзников до +3, разница репутаций при влиянии, вес брони, перегруз, эффекты, жетон Героя).
* Каждый куб: **20 = +2**, **17–19 = +1**, 2–16 = 0, **1 = −2**.
* Если пул равен 0, бросается 1к20, и успехом считается только 20. Если пул меньше нуля, бросается 2к20, и один успех будет, только если на обоих выпало 20.
* Результат: 3+ — блестяще, 2 — успех, 1 — «успех, но…», 0 — неудача, −1 и меньше — провал.
* Клик по характеристике или навыку открывает диалог; **Shift+клик** бросает сразу.

### Молитвы и жетоны Чернобога

* Под каждой проверкой есть кнопка **«Помолиться»**. Щёлкните по кубам, чтобы выбрать, какие перебросить;
  если ничего не выбрано, перебросятся все кубы без успеха.
* После молитвы персонаж получает 1 урон воле сразу и ещё по 1 за каждую выпавшую единицу, а Мастер получает **жетон Чернобога**.
* Атеист (покровитель «Атеист») молиться не может. Поле «Благословение» (после службы в храме или часовне, до 3)
  добавляет к молитве ещё один куб.
* За персонажа Мастера переброс («повторная проверка») стоит Мастеру 1 жетон.
* Счётчик жетонов Чернобога показан над списком игроков; Мастер меняет его кнопками ±.
  Жетоны начисляются автоматически за молитвы, ведовство, активные особые способности и положительные черты; активация отрицательной черты списывает жетон у Мастера.

### Бой

* **Инициатива**: `1к20 + иниц. лучшего экипированного оружия + чистое проворство + бонусы`.
* **Атака** оружием открывает диалог с видом атаки (быстрая −2, мощный удар +2, прицельный +2, от бедра −2,
  автоматический огонь −2…) и дистанцией. Модификатор дистанции считается сам, а за каждый шаг сверх эффективной дальности оружия добавляется −3.
* Хотя бы 1 успех — это попадание. Доп. успехи можно потратить на урон или травму (нужно столько доп. успехов, сколько указано в «Крит.»).
  Кнопки в чате наносят урон целям и бросают к66 по таблице травм.
* **Броня**: цель бросает столько к20, сколько у неё класс защиты брони + укрытие. Каждый успех снижает урон на 1,
  каждая единица снижает класс защиты укрытия или брони на 1. Бронебойность уменьшает броню цели.
* **Здоровье и Воля** могут уходить в минус: при 0 и ниже персонаж выведен из строя (или недееспособен),
  а когда минус превышает половину максимума, персонаж погибает (или сходит с ума). Состояние показано на листе.
* **Проверка здоровья или воли** против силы воздействия (СВЗ/СВВ): бросается столько к20, сколько у персонажа текущее значение;
  устойчивость даёт +3 куба.
* **Особые способности** со знаком * (активные): −1 Воля, Мастеру жетон, повторно — после длительного отдыха (кнопка на листе).

### Нагрузка

Нагрузка считается в ячейках, максимум равен Телосложение×2 + Сила. Вес предмета: маленький 0, лёгкий ½, стандартный 1, тяжёлый 2, громоздкий 4.
Надетая броня и самое тяжёлое оружие в руках считаются на категорию легче. Лёгкая броня или её отсутствие даёт +1 к Проворству и Скрытности,
тяжёлая −2, громоздкая −3 и вдвое снижает скорость. При перегрузе действует −2 ко всем проверкам, кроме силы.
Каждый второй киберимплант снижает максимальную Волю на 1. Уровень персонажа считается по таблице опыта.

### Корабль

* Класс I–V, атрибуты (текущее и максимальное), B-батареи, долг, модули с состоянием (сбоит −1, неисправен −2, крит. неисправен −3).
* **Экипаж**: персонажей перетаскивают на лист корабля и назначают им роль (капитан, пилот, бортинженер, наводчик, стрелок, кибершаман).
  Проверки члена экипажа автоматически учитывают манёвренность (пилотирование), **распределённую энергию** и системный урон
  (отрицательная энергия).
* Кнопки «Инициатива капитана» (к20 + лидерство) и «Инициатива пилота» (к20 + пилотирование + манёвренность, первым ходит меньший результат).
* Оружие корабля: прицельный +2, быстрый −2, очередь −2, залп −3, без захвата цели −2, модификаторы дистанции в сегментах.
  Урон бывает структурный (по Прочности), системный (по Энергии) или оба сразу. Критические провалы при броне корабля броню не снижают.
* Броски к66: критические повреждения, случайный отсек, неудачный прыжок.

### Таблицы к66

В настройках мира можно указать UUID таблиц бросков (травмы, крит. повреждения, случайный отсек, неудачный прыжок)
с диапазонами 11–66. Тогда результат броска к66 будет сразу показан в чате. Таблицы удобно положить в модуль-компендиум.

### Макросы

```js
const actor = game.user.character;
actor.rollSkill("piloting");
actor.rollAttribute("body", { skipDialog: true });
actor.rollResistance("will");
game.starSpindle.DicePool.rollDice({ actor, title: "Ситуативный урон", dice: 6 });
game.starSpindle.DicePool.rollD66("injury");
game.starSpindle.Chernobog.add(1, "Подкрепление");
```

## Компендиумы в отдельном модуле

Система не содержит компендиумов. Модуль с ними создаётся отдельно; в его `module.json` нужно указать
зависимость от системы и паки с `"system": "star-spindle"`:

```json
{
  "id": "star-spindle-compendium",
  "title": "Звёздное Веретено — компендиум",
  "version": "0.1.0",
  "compatibility": { "minimum": "13", "verified": "13" },
  "relationships": {
    "systems": [{ "id": "star-spindle", "type": "system", "compatibility": { "minimum": "0.1.0" } }]
  },
  "packs": [
    { "name": "specializations", "label": "Специализации", "type": "Item", "system": "star-spindle", "path": "packs/specializations" },
    { "name": "abilities", "label": "Особые способности", "type": "Item", "system": "star-spindle", "path": "packs/abilities" },
    { "name": "tables", "label": "Таблицы к66", "type": "RollTable", "path": "packs/tables" },
    { "name": "equipment", "label": "Снаряжение и оружие", "type": "Item", "system": "star-spindle", "path": "packs/equipment" },
    { "name": "ship-parts", "label": "Модули и оружие кораблей", "type": "Item", "system": "star-spindle", "path": "packs/ship-parts" }
  ]
}
```

Типы предметов для паков: `specialization`, `ability`, `trait`, `weapon`, `armor`, `gear`, `implant`, `injury`,
`shipWeapon`, `shipModule`, `shipUpgrade`, `cargo`.

## Структура

```
system.json             манифест системы
module/
  star-spindle.mjs      точка входа: регистрация моделей, листов, настроек
  config.mjs            характеристики, навыки, фракции, кланы, атрибуты корабля
  data/                 модели данных актёров и предметов
  documents/            классы Actor и Item (броски, урон)
  dice/pool.mjs         пул к20, молитвы, урон и броня, сопротивление, к66
  chernobog.mjs         счётчик жетонов Чернобога
  sheets/               листы персонажа, НИП, корабля и предметов (ApplicationV2)
templates/              Handlebars-шаблоны
styles/                 оформление
lang/                   русский и английский
```

## Релиз

Создайте релиз на GitHub с тегом вида `v0.1.0`. Workflow `.github/workflows/release.yml` подставит версию в `system.json`,
соберёт `star-spindle.zip` и прикрепит оба файла к релизу, после чего ссылка на манифест выше начнёт работать.
